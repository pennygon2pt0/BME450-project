# BME450-project
# Title

Classification of Bone Fractures from X-Rays

## Team members

Patricia Hung (pennygon2pt0), Kelly Lin (kellyhlin)

## Project decription

- We plan to use dataset from Kaggle (https://www.kaggle.com/datasets/bmadushanirodrigo/fracture-multi-region-x-ray-data/code)
- The dataset consists of training, testing, validation data (PNG, JPG) for fractured and not fractured bones
- The goal of the project is to classify whether or not a bone is fractured based on X-Ray images. This can be useful for clinical settings to help diagnose bone fractures quickly. It could also potentially help with diagnosing bone fractures in images where the fracture is not obvious.
