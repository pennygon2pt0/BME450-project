# BME450-project
# Title

Classification of Sleep Stages from EEG Data

## Team members

Patricia Hung (pennygonn2pt0), Kelly Lin (kellyhlin)

## Project decription

- We plan to use dataset from Kaggle (https://www.kaggle.com/datasets/iamommpatel/physiobank-database-sleep-edfx-cassette)
- The dataset consists of EEG recordings and annotations of sleep stages (wake, non-rapid eye movement sleep stages (N1, N2, N3), rapid eye movement (REM) sleep).

- The goal of the project is to classify sleep stages from EEG data.
