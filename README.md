## Project decription

- We plan to use dataset from Kaggle (https://www.kaggle.com/datasets/iamommpatel/physiobank-database-sleep-edfx-cassette)
- The dataset consists of polysomnographic data that includes EEG recordings and annotations of sleep stages (wake, non-rapid eye movement sleep stages (N1, N2, N3), rapid eye movement (REM) sleep).

- The goal of the project is to classify sleep stages from EEG.
